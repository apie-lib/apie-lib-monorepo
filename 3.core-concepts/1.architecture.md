# 1.Architecture
Apie itself is built around 30+ Composer packages.

## Composer packages:

### Internal packages:
These are a few:
- Apie/core is required to make Apie domain objects. It contains all attributes for permission checks and interfaces to make domain objects. It's the minimal depedency you need.
- Apie/common is required for any 'Apie engine' and contains shared logic, for example functionality to give all available actions etc. For example it contains logic if the object can be edited so we do not make edit functionality for immutable domain objects.
- Apie/common-plugin is a composer plugin that can be used to see what Value objects etc. were loaded with Composer.
- Apie/apie-phpstan-rules adds custom phpstan rules for Apie objects.
- Apie/meta-minimum, apie/meta-maximum and apie/meta-recommended are meta packages that just add a large list of composer dependencies.
- Apie/html-builders: is used internally by apie/cms which component to render
- Apie/twig-template-layoyt-renderer: is the twig rendered used internally by layouts of apie/cms

### Framework-binding packages:
Right now we have a binding for Laravel: apie/laravel-apie and for the Symfony framework: apie/apie-bundle. They connect Apie with
a framework. Most of these packages also add functionality specific for the framework. For example laravel-apie adds a Laravel facade
for Apie. The framework bindings do very little: you still need to include apie/rest-api to add a REST API to your application.

### Apie engine packages:
With an Apie engine I mean packages that add some global functionality to an application.
- Apie/rest-api adds a fully working REST API with OpenAPI spec and Swagger UI interface.
- Apie/cms adds an admin panel including authorization, pagination, search filters etc.
- Apie/console adds console commands that can call any Apie functionality from the terminal.
- Apie/faker creates domain objects with random data to have seeded data.
- Apie/ai-instructor creates a PHP version of the instructor tool to map textual content to a predefined data structure.
- Apie/mcp-server creates a MCP server 

### Value object packages:
Adds very common value objects to an application, so you do not need to develop them from scratch:
- Apie/common-value-objects adds a list of common value objects, for example e-mail value objects and html contents etc.
- Apie/country-and-phone-number adds phone number value objects
- Apie/date-value-objects adds date and time related value objects
- Apie/otp-value-objects adds value objects for HOTP and TOTP.
- Apie/regex-value-objects: adds value objects that represent regular expressions.
- Apie/text-value-objects: adds a list of common value objects that are represented as strings.

### Apie/cms layout packages:
They contain a layour for how to display apie/cms:
- Apie/cms-layout-ionic
- Apie/cms-layout-graphite
- Apie/cms-layout-ugly

### High-level reusable functionality:
These are packages that contain functionality often used by one or more engines that can be used standalone without the engine package.
- Apie/count-words: counts words in strings and in files. Used mainly for indexing.
- Apie/dateformat-to-regex: converts a PHP datetime format string into a regular expression.
- Apie/maker: scaffolding code for creating Apie domain objects etc.
- Apie/regex-tools: adds functionality for modifying/checking regular expressions.
- Apie/schema-generator: creates OpenAPI specs from PHP objects with Reflection.
- Apie/serializer: the internal Serializer Apie uses.
- Apie/storage-metadata-builder and apie/storage-metadata: used to make object mappers.
