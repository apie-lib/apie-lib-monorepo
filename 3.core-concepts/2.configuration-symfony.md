# Configuration (Symfony)

In Symfony, Apie is configured via the `apie-bundle`. After installing the bundle, you can create a configuration file at `config/packages/apie.yaml`.

## Basic Configuration

The most important part of the configuration is defining your **Bounded Contexts**. This tells Apie where to find your domain objects and actions.

```yaml
apie:
  bounded_contexts:
    default:
      entities_folder: "%kernel.project_dir%/src/Apie/Resources/"
      entities_namespace: 'App\Apie\Resources'
      actions_folder: "%kernel.project_dir%/src/Apie/Actions/"
      actions_namespace: 'App\Apie\Actions'
```

## Configuration Options

- `entities_folder`: The absolute path to the folder containing your Apie entities.
- `entities_namespace`: The PHP namespace for your entities.
- `actions_folder`: The absolute path to the folder containing your Apie actions.
- `actions_namespace`: The PHP namespace for your actions.

## Integration

Apie integrates with Symfony's security, routing, and dependency injection. If you have `apie/rest-api` installed, it will automatically register the necessary routes to expose your domain objects via a REST API.
