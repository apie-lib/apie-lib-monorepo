# Core Concepts

Apie is built on several key concepts that allow it to automate the boring parts of application development.

In this section, you will find:

1. [Architecture](./1.architecture.md) - How Apie is structured and its ecosystem of packages.
2. [Configuration (Symfony)](./2.configuration-symfony.md) - How to configure Apie in a Symfony application.
3. [Configuration (Laravel)](./3.configuration-laravel.md) - How to configure Apie in a Laravel application.

## Key Pillars

- **Domain-Driven Design (DDD)**: Apie puts your domain objects at the center.
- **Value Objects**: Small, immutable objects that represent a single value with validation.
- **Bounded Contexts**: Logical boundaries within your application to organize domain objects and actions.
- **Data Layers**: Abstractions for persisting and retrieving your domain objects.
