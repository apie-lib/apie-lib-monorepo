# OpenAPI Module

The `apie/schema-generator` and `apie/rest-api` packages work together to provide automatic OpenAPI (Swagger) documentation for your application.

## Key Features

- **Automated Spec Generation**: Generates an OpenAPI 3.0/3.1 specification based on your domain objects, actions, and types.
- **Type-Safe**: Uses PHP reflection and Apie's type system to accurately map PHP types to JSON Schema.
- **Interactive UI**: Includes Swagger UI or Redoc out of the box when using the REST API module.
- **Customizable**: You can enrich the generated spec using attributes like `#[Description]`, `#[Pattern]`, or by providing custom schema providers.

## How it Works

Apie analyzes your entities and actions, identifying inputs (parameters) and outputs (return values). It then builds a schema for each type, including complex objects and collections, ensuring that your API documentation is always in sync with your code.
