# MCP Server Module

The `apie/mcp-server` package implements the [Model Context Protocol (MCP)](https://modelcontextprotocol.io/), allowing AI agents (like Claude or ChatGPT) to interact directly with your Apie-powered application.

## Key Features

- **Agentic Integration**: Expose your domain actions and resources as "tools" that an AI agent can call.
- **Context-Aware**: The agent can query your domain objects to understand the current state of the application.
- **Secure**: All calls from the AI agent are subject to Apie's standard security and validation rules.
- **Real-Time Data**: Provides the AI with live access to your application's data and logic.

## Usage

By installing the `apie/mcp-server` module, your application becomes an MCP server. You can then connect your favorite AI client or agent to this server, allowing it to perform tasks like "Create a new order for user X" or "What is the status of order #123?".

```bash
composer require apie/mcp-server
```

## IDE Configuration

### VS Code

To use the Apie MCP server with VS Code (using an extension like Claude Dev or similar MCP-compatible tools), you can configure it to run the Apie console command via `stdio`.

Add the following to your MCP configuration (e.g., `mcp.json`):

**For Symfony:**
```json
{
  "mcpServers": {
    "apie": {
      "command": "php",
      "args": ["bin/console", "apie:mcp-server"]
    }
  }
}
```

**For Laravel:**
```json
{
  "mcpServers": {
    "apie": {
      "command": "php",
      "args": ["artisan", "apie:mcp-server"]
    }
  }
}
```

### Gemini (Google AI Studio / Custom Agents)

When configuring a Gemini agent or any tool that supports the Model Context Protocol, you can point it to your Apie application. If the agent supports local command execution, use the same `php bin/console apie:mcp-server` or `php artisan apie:mcp-server` command.

For remote agents, ensure your Apie application is reachable via HTTP and that the `apie/mcp-server` package is configured to handle MCP requests over HTTP (refer to the package-specific documentation for HTTP setup).

Refer to the specific integration guides for connecting your AI agent to the Apie MCP server.
