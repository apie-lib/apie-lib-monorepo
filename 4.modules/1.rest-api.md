# REST API Module

The `apie/rest-api` package provides a fully-functional, HATEOAS-compliant REST API based on your domain objects.

## Key Features

- **Automatic Route Generation**: CRUD operations (GET, POST, PUT, PATCH, DELETE) are automatically created for your entities.
- **Action Endpoints**: Public methods on your domain objects or dedicated action classes are exposed as RPC-style endpoints.
- **Content Negotiation**: Supports multiple formats (JSON, XML, etc.) via the serializer.
- **Filtering and Sorting**: Built-in support for filtering lists based on getters or public properties.
- **Validation**: Automatically validates incoming data based on typehints and value object constraints.

## Usage

Simply install the package:

```bash
composer require apie/rest-api
```

Once installed and configured in your framework binding, your API will be available at the configured `base_url` (e.g., `/api`).
