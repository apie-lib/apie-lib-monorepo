# Serializer Module

The `apie/serializer` package is the core engine for converting PHP objects to and from various formats (JSON, XML, YAML).

## Key Features

- **Normalization and Denormalization**: High-performance conversion of complex object graphs.
- **Context-Aware**: Serialization can be adjusted based on the current context (e.g., user permissions, requested format).
- **Value Object Support**: Deep integration with Apie value objects for seamless conversion.
- **Extension Points**: Register custom normalizers or encoders to handle specific types or formats.

## How it Works

When an API request comes in, the Serializer *denormalizes* the raw input into PHP objects. When sending a response, it *normalizes* your domain objects back into a format like JSON. It ensures that validation rules are respected and that sensitive data is filtered based on the current context.
