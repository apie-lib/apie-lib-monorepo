# Faker Module

The `apie/faker` package allows you to generate realistic fake data for your domain objects, making it easy to seed databases or perform load testing.

## Key Features

- **Domain-Aware Faking**: Understands Apie value objects and generates appropriate data for them (e.g., valid emails, phone numbers).
- **Recursive Generation**: Can generate entire object graphs, including nested entities and collections.
- **Customizable**: You can provide your own fakers for specific classes or value objects.

## Usage

### Framework Usage (Laravel/Symfony)

When using Apie within a framework, the `ApieObjectFaker` is usually available in the service container.

```php
// In a controller or command
$faker = $container->get(ApieObjectFaker::class);
$order = $faker->fakeClass(Order::class);
```

### Standalone Usage (Without Framework)

If you are using the package standalone, you can integrate it directly with the standard [FakerPHP](https://fakerphp.org/) library by adding it as a provider.

```php
use Apie\Faker\ApieObjectFaker;
use Faker\Factory;

// 1. Create a standard Faker generator
$faker = Factory::create();

// 2. Add ApieObjectFaker as a provider
$faker->addProvider(ApieObjectFaker::createWithDefaultFakers($faker));

// 3. Now you can fake Apie domain objects and value objects
$order = $faker->fakeClass(Order::class);

// You can also fake from a PHP ReflectionType
$type = new ReflectionType(...);
$value = $faker->fakeFromType($type);
```
