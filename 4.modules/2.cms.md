# CMS Module

The `apie/cms` package provides a powerful, auto-generated admin panel for your application.

## Key Features

- **Zero Configuration**: The CMS is generated automatically from your domain model.
- **Rich UI Components**: Uses `apie/html-builders` to render appropriate UI components for your value objects and properties.
- **Search and Filters**: Integrated search and filtering for all your resources.
- **Customizable Layouts**: Choose from multiple layouts like `ionic`, `graphite`, or create your own.
- **Action Support**: Call your domain actions directly from the CMS UI.

## Usage

Install the package and a layout:

```bash
composer require apie/cms apie/cms-layout-graphite
```

The CMS will be available at the configured `base_url` (e.g., `/cms`).
