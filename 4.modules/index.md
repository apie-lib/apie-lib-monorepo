# Apie Modules

Apie is highly modular. You only install what you need. Each module adds a specific capability to your domain-driven application.

In this section, you will find details about the core modules:

1. [REST API](./1.rest-api.md) - Automatically expose your domain objects as a REST API.
2. [CMS](./2.cms.md) - A full-featured admin panel generated from your domain.
3. [Faker](./3.faker.md) - Generate realistic fake data for your domain objects.
4. [OpenAPI](./4.open-api.md) - Automatic OpenAPI (Swagger) documentation generation.
5. [Data Integration](./5.data-integration.md) - Connecting Apie to your database or other storage.
6. [Serializer](./6.serializer.md) - How Apie handles object conversion and normalization.
7. [AI Instructor](./7.ai-instructor.md) - Use LLMs to map text to your domain objects.
8. [Console](./8.console.md) - Interact with your domain through CLI commands.
9. [MCP Server](./9.mcp-server.md) - Model Context Protocol server for AI agent integration.
