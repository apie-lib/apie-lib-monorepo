# AI Instructor Module

The `apie/ai-instructor` package bridges the gap between Large Language Models (LLMs) and your structured domain model. It allows you to use AI to process unstructured text and map it directly to your Apie objects.

## Key Features

- **Text-to-Object Mapping**: Provide a text prompt and have the AI return a fully-instantiated Apie object or collection.
- **Provider Agnostic**: Supports multiple AI providers, including OpenAI, Ollama, and more.
- **Type-Safe Prompts**: Automatically generates the required JSON Schema from your PHP types to guide the AI's response.
- **Validation**: The resulting objects are subject to the same validation rules as any other Apie object.

## Usage

### Framework Usage (Laravel/Symfony)

When using Apie within a framework, the `AiInstructor` is typically available in the service container.

```php
// In a controller or command
$instructor = $container->get(AiInstructor::class);

$order = $instructor->instruct(
    Order::class,
    'gpt-4o',
    'You are an order processing assistant.',
    'I want to order a pizza to pizza@example.com and my phone number is 0612345678'
);
```

### Standalone Usage (Without Framework)

For standalone usage, you can manually instantiate the `AiInstructor` and its dependencies.

```php
use Apie\AiInstructor\AiClient;
use Apie\AiInstructor\AiInstructor;
use Apie\SchemaGenerator\ComponentsBuilderFactory;
use Apie\SchemaGenerator\SchemaGenerator;
use Apie\Serializer\Serializer;
use Symfony\Component\HttpClient\HttpClient;

// 1. Setup the Schema Generator
$schemaGenerator = new SchemaGenerator(
    ComponentsBuilderFactory::createComponentsBuilderFactory()
);

// 2. Setup the Serializer
$serializer = Serializer::create();

// 3. Setup the AI Client (Ollama example)
$aiClient = AiClient::create(
    HttpClient::create(),
    'http://localhost:11434', // Ollama base URL
    'ignored'
);

// 4. Instantiate the AI Instructor
$instructor = new AiInstructor($schemaGenerator, $serializer, $aiClient);

// 5. Use it to map text to domain objects
$order = $instructor->instruct(
    Order::class,
    'llama3',
    'You are an order processing assistant.',
    'I want to order a pizza to pizza@example.com and my phone number is 0612345678'
);
```

This will call the LLM, receive a structured response, and denormalize it into an `Order` entity, validating the email and phone number in the process.
