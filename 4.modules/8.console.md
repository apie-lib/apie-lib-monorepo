# Console Module

The `apie/console` package allows you to interact with your domain model directly from the command line.

## Key Features

- **Automatic Command Generation**: Every action and resource in your bounded context is automatically exposed as a console command.
- **Interactive Input**: Commands can prompt for missing information interactively.
- **Validation**: Input is validated against your domain's types and value objects.
- **Framework Integration**: Integrates seamlessly with Symfony Console and Laravel Artisan.

## Usage

List all available Apie commands:

```bash
php bin/console list apie  # Symfony
php artisan list apie      # Laravel
```

Call an action from the console:

```bash
php bin/console apie:example:calculator:run:sum --input-numbers "[1, 2, 3]"
```

The console module makes it easy to run migrations, seed data, or perform administrative tasks directly from your terminal.
