# Roadmap

Apie has evolved through several release candidates, each introducing key features and stability improvements.

## 🏁 Version 1.0.0 (Current)

The 1.0.0 release focuses on stability, comprehensive documentation, and advanced AI integrations.

- **Stability**: Refined core APIs and improved test coverage across all 30+ packages.
- **AI Integration**: Introduction of `apie/ai-instructor` and `apie/mcp-server` for bridging the gap between LLMs and structured domain models.
- **Modern PHP**: Full support for PHP 8.2, 8.3, and 8.4 features, including property hooks.
- **Documentation**: A complete rewrite of the documentation (which you are reading now).

## 📜 History & Release Candidates

- **Release Candidate 1 (April)**: The initial stable preview. Although it encountered minor deployment issues, it set the foundation for the library.
- **Release Candidate 2 (June)**: Added significant features, including improved OpenAPI spec generation and the initial introduction of `apie/ai-instructor` for mapping text to domain objects.
- **Release Candidate 3 (In Progress/Transition)**: Focused on becoming "LLM friendly," rewriting the documentation, and introducing the `apie/mcp-server` package to link Apie objects to AI agents.

## 🚀 Future Roadmap

- **GraphQL Support**: Native GraphQL API generation alongside REST.
- **Improved Performance**: Further optimizations in the serializer and schema generator.
- **More Framework Bindings**: Exploring integrations beyond Symfony and Laravel.
- **Expanded Layouts**: New and improved UI layouts for the CMS module.
- **Advanced Export/Import**: Better support for bulk data operations (CSV, Excel, etc.).
