## 4. Roadmap
Apie is currently in release candidate status. Release candidate 1 released in april (but this release was buggy because of a small issue with the deploy tool).
Release candidate 2 followed in june added some nice features like improving the generated OpenAPI spec and also the introduction of apie/ai-instructor to map textual content to an object.
Release candidate 3 is now in progress. It has even more options for being LLM friendly and a rewrite for the documentation. This release may also introduce the new package apie/mcp-server to link Apie domain objects to an AI agent.
