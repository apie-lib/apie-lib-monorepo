# Root aggregates
Root aggregates are entities that are allowed to have references to its own child entities. The best example is a web order that contains multiple order lines.

In Apie, a root aggregate should implement `Apie\Core\Entities\RootAggregate`.

```php
use Apie\Core\Entities\RootAggregate;
use Apie\Core\Entities\EntityInterface;

class Order implements RootAggregate
{
    private OrderId $id;

    /** @var OrderLine[] */
    private array $orderLines = [];

    public function __construct(OrderId $id)
    {
        $this->id = $id;
    }

    public function getId(): OrderId
    {
        return $this->id;
    }

    public function addOrderLine(OrderLine $orderLine): void
    {
        $this->orderLines[] = $orderLine;
    }

    /**
     * @return OrderLine[]
     */
    public function getOrderLines(): array
    {
        return $this->orderLines;
    }
}
```

Root aggregates are the main entry point for persisting data. When you save a root aggregate, Apie will also ensure that all child entities and value objects are persisted correctly according to the data layer implementation.
