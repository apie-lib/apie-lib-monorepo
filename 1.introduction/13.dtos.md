# Data Transfer Objects
Data transfer objects (or DTOs) are simple objects with public properties and no business logic. They are used to transfer data between different parts of the application or between the application and external systems.

To tell Apie that an object should be treated as a DTO, it should implement the marker interface `Apie\Core\Dto\DtoInterface`.

```php
use Apie\Core\Dto\DtoInterface;

class Address implements DtoInterface {
    public string $street;
    public ?string $streetNumber = null;
    public string $city;
    public string $country;
}
```

It is also possible to use promoted properties:
```php
use Apie\Core\Dto\DtoInterface;

class Address implements DtoInterface {
    public function __construct(
        public string $street,
        public string $city,
        public string $country,
        public ?string $streetNumber = null,
    ) {
    }
}
```

## Optional fields
By default, all fields are considered required unless they have a default value or the `Optional` attribute is assigned to the property.

```php
use Apie\Core\Attributes\Optional;
use Apie\Core\Dto\DtoInterface;

class Address implements DtoInterface {
    public string $street;
    public ?string $streetNumber = null;
    
    #[Optional]
    public string $streetNumberSuffix; // This field is optional and has no default value.
    
    public string $city;
    public string $country;
}
```

When using `#[Optional]` without a default value, Apie will use [newInstanceWithoutConstructor](https://www.php.net/manual/en/reflectionclass.newinstancewithoutconstructor.php) to instantiate the DTO, allowing the property to remain uninitialized if not provided.
