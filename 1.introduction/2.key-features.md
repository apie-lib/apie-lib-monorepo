# 2. Key features
Benefits:
- Apie is framework agnostic. You need a wrapper library to link Apie to your framework. Right now you can integrate it in Symfony or in Laravel.
- I can move any Apie domain object to an other application without any changes required in the other application, except for obvious things (like changing the namespace of the library).
- A good REST API is only possible with a focus on small details, like content negotation, filtering and OpenAPI specs. Apie does this out of the box so you do not need to look at it.
- Apie is very opinionated so there is no initial discussing how you should structure the code. It also makes the library lean to maintain.
- Apie generates a very efficient database optimized for retrieving and filtering data as efficient as possible. Apie make sure you do not need to think about it.
