# 📌 3. Use Cases

**Apie** is designed for developers who want to focus on **business logic**, not on glue code. Apie treats your **domain objects as the center of your application**, with everything else—APIs, admin panels, console commands—plugging into them.

---

## 🧠 Centralizing Business Logic

Use Apie when:

- You want **all domain logic**—validation, behavior, input/output—in a **single class**.
- You’re tired of duplicating logic across controllers, form requests, and serializers.
- You want one place to add/modify behavior and have it reflected everywhere: API, console, admin panel.

---

## 🛠️ Building APIs Without Writing Controllers

Apie generates:

- Fully functional **REST APIs** with OpenAPI documentation
- Admin interfaces
- Console commands

...all **without needing explicit controllers or routes**.

---

## 🧩 Plug-and-Play Architecture

Apie lets you:

- Copy/paste domain objects between applications or frameworks
- Add features like **GraphQL**, **CSV/XLS export**, or **full-text search** by including packages (or in the future)

---

## 🔐 4. Secure, Context-Aware Business Logic

Apie supports:

- Context injection via `#[Context]` (e.g. logged-in user, locale)
- Realtime permissions via `#[RuntimeCheck]` and disabling options with `#[StaticCheck]` attribute
- Value objects to prevent invalid states and reuse and clarity of your domain objects.

---

## ⚙️ 5. Domain-Driven Design Without Glue Code

For developers using **DDD**, Apie supports:

- Rich domain models and immutable **value objects**
- Entities separated from ORM persistence
- Aggregate roots and bounded contexts
- Behavior-oriented design like `User::activate()` as first-class logic

---

## 💻 6. Developer Experience

Apie is ideal for teams who:

- Want clean, testable, self-documenting business logic
- Are tired of boilerplate-heavy frameworks
- Need to ship internal tools or headless APIs fast

---

Apie is not just a framework—it’s a philosophy: build the domain, and let Apie wrap around it.
