# Background Jobs

Apie allows you to offload time-consuming or complex tasks to background processes. Unlike traditional frameworks that might use an `#[Async]` attribute on a method, Apie uses a domain-driven approach where an action returns a `BackgroundProcess` object.

## How it Works

To create a background job in Apie, your domain action must return an instance of `Apie\Core\BackgroundProcess\SequentialBackgroundProcess`. This object represents a task that can be executed in one or more steps.

Apie detects when an action returns a `BackgroundProcess` and automatically handles the queuing and status tracking.

## Implementation Steps

### 1. Create a Background Process Declaration

First, you need a class that implements `BackgroundProcessDeclaration`. This class defines the sequential steps of your background task. Each step is a callable that receives the `ApieContext` and the `payload`.

```php
namespace App\Apie\BackgroundTasks;

use Apie\Core\BackgroundProcess\BackgroundProcessDeclaration;
use Apie\Core\Context\ApieContext;
use Apie\Core\Lists\ItemHashmap;

class MyExpensiveTask implements BackgroundProcessDeclaration
{
    /**
     * Define the steps of the process.
     * The result of one step is passed to the next step via the ApieContext.
     */
    public static function retrieveDeclaration(int $version): array
    {
        return [
            // Step 1: Initialization
            function (ItemHashmap $payload, ApieContext $context) {
                $input = $payload['input'];
                // Perform some heavy logic...
                return ['initial_result' => $input * 2];
            },
            // Step 2: Finalization
            function (ItemHashmap $payload, ApieContext $context) {
                // Access result from previous step
                $previousResult = $context->getRawContext('background_process');
                
                // Final processing...
                return "Task finished with: " . $previousResult['initial_result'];
            }
        ];
    }

    public function getCurrentVersion(): int
    {
        return 1;
    }

    public static function getMaxRetries(int $version): int
    {
        return 3; // Retry up to 3 times on failure
    }
}
```

### 2. Return the Process from an Action

In your domain object or action class, return a `SequentialBackgroundProcess` initialized with your declaration and any required payload.

```php
namespace App\Apie\Actions;

use Apie\Core\BackgroundProcess\SequentialBackgroundProcess;
use Apie\Core\Lists\ItemHashmap;
use App\Apie\BackgroundTasks\MyExpensiveTask;

class Calculator
{
    public function expensiveCalculation(int $input): SequentialBackgroundProcess
    {
        return new SequentialBackgroundProcess(
            new MyExpensiveTask(),
            new ItemHashmap(['input' => $input])
        );
    }
}
```

## Key Features

- **Step-by-Step Execution**: Large tasks can be broken down into multiple smaller steps.
- **Automatic Persistence**: Apie automatically saves the state and progress of the background process in your data layer.
- **Status Tracking**: You can query the status of a process (Active, Completed, Failed, Canceled) via the API or CMS.
- **Retries and Error Handling**: Configurable retry logic via `getMaxRetries`.

## Monitoring

Once a background process is started, it is treated as a first-class entity in Apie. You can see it in the CMS, track its progress, and even cancel it if it's still active. If you are using `apie/rest-api`, Apie will provide links to check the status of the process in the response.
