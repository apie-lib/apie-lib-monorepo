# Error Handling

Apie provides a robust and consistent way to handle errors across all modules (REST API, CMS, Console).

## Validation Errors

When a value object fails validation or a required field is missing, Apie throws a `ValidationException`. This exception contains a map of field names to error messages, which is automatically converted into a structured error response:

- **REST API**: Returns a `422 Unprocessable Entity` status code with a JSON body detailing the errors.
- **CMS**: Displays the error messages next to the relevant form fields.
- **Console**: Prints a formatted error list to the terminal.

## Customizing Error Responses

You can customize how errors are rendered by implementing a custom error renderer or by using framework-specific error handling mechanisms.

## Exception Mapping

Apie allows you to map specific PHP exceptions to HTTP status codes or user-friendly error messages, ensuring that internal implementation details are not leaked to the user.
