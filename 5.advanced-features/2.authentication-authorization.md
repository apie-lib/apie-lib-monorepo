# Authentication and Authorization

Securing your application is a first-class citizen in Apie. It uses attributes and context-aware logic to ensure that only authorized users can access specific resources or perform certain actions.

## Authentication

Apie integrates with your framework's authentication system (e.g., Symfony Security or Laravel Auth). The authenticated user is automatically injected into the Apie context and can be accessed within your domain objects.

## Authorization

Authorization is handled through Apie attributes:

- **`#[RequiresPermission('permission_name')]`**: Ensures the user has a specific permission before they can call an action or access a resource.
- **`#[StaticCheck]`**: Used for checks that can be determined without the object's state (e.g., "Is the user an admin?").
- **`#[RuntimeCheck]`**: Used for checks that depend on the current state of the object (e.g., "Can this user edit *this* specific order?").

## Context Injection

You can use the `#[Context]` attribute to inject the current user or other contextual data directly into your domain methods:

```php
public function updateProfile(#[Context] User $currentUser, string $newName): void
{
    // ...
}
```

This makes your domain logic clean and easy to test, while Apie handles the plumbing of fetching the correct data from the framework.
