# Getting Started with Apie

Welcome to Apie! This section will help you get up and running quickly.

In this section, you will find:

1. [Installation](./1.installation.md) - Learn how to install Apie using Composer, Docker, or manually in your existing project.
2. [Quick Start](./2.%20quickstart.md) - A step-by-step guide to building your first Apie application.

## Prerequisites

- **PHP >= 8.2** (PHP 8.4+ recommended)
- **Composer**
- Required PHP extensions: `json`, `mbstring`, `ctype`, `dom`, `fileinfo`, `reflection`, `tokenizer`.
