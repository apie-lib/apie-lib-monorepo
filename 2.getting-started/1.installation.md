# 1. Installation
There are 4 ways to intall Apie depending on what you need.

## ✅ Prerequisites

Before installing Apie, make sure your development environment meets the following requirements:

- **PHP >= 8.2**  
  Apie uses modern PHP features like attributes, union types, and readonly properties.
  PHP 8.4 property hooks are also fully supported. We do not have all the tests running PHP8.5 yet, but we do think PHP 8.5 will work fine.

- **Composer**  
  Apie is installed via [Composer](https://getcomposer.org/). Make sure it's available in your system:

  ```bash
  composer --version
  ```

- **Required PHP Extensions**  
  Ensure the following PHP extensions are enabled:

  - `json`
  - `mbstring`
  - `ctype`
  - `dom`
  - `fileinfo`
  - `reflection`
  - `tokenizer`

You can check installed extensions with:

```bash
php -m
```

> 💡 Tip: If you're using Docker, consider starting from an image like `php:8.2-cli` and installing extensions with `docker-php-ext-install`.


## With the composer skeleton starter
The composer skeleton starter is a composer create-project skeleton. It will ask a few question interactively (like does it need to make an User domain object for you and should it run in Symfony or Laravel). To do this type this in a terminal:
```bash
composer create-project apie/apie-project-starter app -s dev
```

## Using the apie docker image
The Apie docker image is available on [Dockerhub](https://hub.docker.com/r/apieprogrammer/apie)
The easiest setup is with a docker-compose.yaml file:
```yaml
services:
  app:
    image: apieprogrammer/apie:symfony-cli-8.4
    container_name: myapp
    environment:
      APP_ENV: production
    ports:
      - "8000:8000"
    volumes:
      - ./domains:/app/domains
    networks:
      - application

networks:
  application:
```

In a terminal run this to start the container:
```bash
mkdir -p domains
docker compose build && docker compose up -d
```
Now you have a working Apie application on localhost:8000.

Now we can make an Apie domain object with a console command. We picked the symfony image, so Apie is using the Symfony framework
here, so we do this:
```bash
docker exec myapp php bin/console apie:create-domain-object -b example Test
```
If you use a Laravel image, replace bin/console with artisan
